# LinkGlancer Design

这里补充下游审核阶段 `LinkGlancer` 自身的实现约束。

- `browser-control.md`: 审核浏览器会话与确认页约束
- `developer-mode.md`: 开发者模式开关、标题标识与诊断日志
- `runtime-layout.md`: 运行时目录与开发回退路径
- `storage-model.md`: 持久化边界
- `task-configuration.md`: 任务快照与导入/导出边界
- `review-ui.md`: 审核流程里的非直观交互约束

与上游采集阶段的关系放在 `../workflow/`，这里不重复定义。
