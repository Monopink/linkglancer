# Review UI Notes

- 主窗口保持轻量，浏览器页面不内嵌。
- 检查快捷键只在检查窗口生效。
- `always-on-top` 只属于检查窗口，不属于主窗口。
- 检查窗口标题统一使用“人工检查”。
- 检查窗口需要明确展示当前人工检查范围。
- 自动初筛结果列在存在机器结果后应出现在人工检查面板中。

## 双指针语义

- `current_task_index` 表示真正待正式提交的当前检查项。
- `viewing_task_index` 表示检查窗口当前正在浏览或编辑的条目。
- `viewing_task_index` 的可移动范围仅限：
  - 已提交条目
  - 当前检查项
- 不允许浏览到任何未检查条目。

## 检查与回看模式

- 当 `viewing_task_index == current_task_index` 时，窗口处于当前检查模式。
- 当 `viewing_task_index < current_task_index` 时，窗口处于历史回看模式。
- 历史回看模式支持：
  - 上一条
  - 下一条
  - 修改已提交结果
- 历史回看模式不影响浏览器状态，不切换当前检查页。

## 提交、保存和草稿

- 当前检查模式下：
  - `提交` 会保存正式结果并推进 `current_task_index`
  - 提交成功后才关闭当前检查页并触发补页
- 历史回看模式下：
  - 保存动作只覆盖该条已提交结果
  - 不推进任务，不影响浏览器
- 当前检查项存在未提交修改时，切换到历史条目会先把表单内容保存为当前项草稿。
- 退出检查时保留：
  - 已提交结果
  - 当前项草稿
  - 任务进度

## 选项显示

- 选择类检查项只有单一“选项”文本，不再区分内部值与显示名。
- 快捷键绑定到“选项”本身，导出结果也直接使用该文本。
- `screen` 检查项不使用普通选项列表；界面直接展示“通过 / 不通过”两个可配置值。
- 自动初筛结果列虽然是系统字段，但人工检查阶段允许人工修改其最终值。
