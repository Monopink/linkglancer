# Task Snapshot Notes

- 任务是核心工作单元，一个源 `xlsx` 可以生成多个独立任务。
- 创建任务时立即导入源行，并把当时的任务配置和浏览器配置快照写入 SQLite。
- 任务后续允许更新快照；恢复检查、继续检查、导出都读取当前已保存快照，而不是重新读取旧表单状态。
- 浏览器配置仍然是唯一独立的全局配置面。
- 检查字段定义继续支持全局复用，并在任务创建时写入任务快照。
- 导出字段同时允许引用源列和检查结果列；同名时以检查结果覆盖源值。
- 任务快照额外保存：
  - `manual_review_scope`
  - `export_scope`
  - `enrichment_scope`
  - `machine_screening_config`

## 任务快照语义

- 打开页数表示最大页面窗口上限，而不是启动时一次性全部打开。
- 选择类检查项的选项只有一个统一文本值，不再区分值和显示名。
- 新增 `screen` 检查项类型：
  - 结果为 `通过 / 不通过 / 空白`
  - `通过` 与 `不通过` 的展示值可配置
  - `screen` 检查项不配置普通选项列表
- 自动初筛结果列不是普通用户配置项：
  - 系统固定 `field_id = "__machine_screening__"`
  - 默认标签 `自动初筛结果`
  - 未发生自动初筛结果前，人工检查界面可隐藏该列
- 自动初筛配置当前第一版支持：
  - `top_video_count`
  - `metric_type`：`sum` / `avg` / `median`
  - `play_count_threshold`
  - 固定排除置顶视频
- 已创建任务中的检查项 `field_id` 仍然视为稳定结果列名，不随历史数据自动迁移。
- 任务快照需要支持：
  - 当前检查项正式结果
  - 当前检查项草稿恢复
  - 历史回看与覆盖保存
