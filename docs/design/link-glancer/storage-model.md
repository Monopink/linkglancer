# Storage Notes

- SQLite 是运行时单一事实源，源 `xlsx` 只在创建任务时参与导入。
- `tasks` 保存任务元数据、当前指针、当前浏览指针、任务快照和浏览器快照。
- `task_items` 保存导入后的稳定顺序数据；检查和导出都基于这里的数据。
- `reviews` 保存每条任务项的当前正式结果；重新编辑同一条时直接覆盖。
- `machine_screening_results` 单独保存每条任务项的自动初筛结果、结构化细节和错误信息。
- 任务项草稿与正式结果分离保存；草稿只用于当前检查项未正式提交时的恢复。
- 不再保留 `review_history` 表，也不再写入审计历史。
- 删除浏览器配置不会影响已有任务，因为任务已经保存了自己的浏览器快照。
- 自动初筛执行逻辑不直接耦合到 `link_glancer` 人工检查运行时；任务内只保存其结果字段和范围配置。
- 人工检查完成度只由 `reviews` 决定；自动初筛写入不得污染人工完成度。

## 检查项结构

- `ReviewField` 继续保存字段定义、类型、必填状态和选项列表。
- `ReviewOption` 只保存：
  - `value` 作为唯一选项文本
  - `shortcut`
- `screen` 检查项额外保存：
  - `screen_pass_value`
  - `screen_fail_value`
  - `source`
- `screen` 汇总结果不单独落库字段；统一由任务快照中的启用筛选项和当前检查结果实时计算。
- 自动初筛系统字段的展示值读取采用：
  - 人工值优先
  - 机器结果回退
- 自动初筛备注写入当前复用采集任务默认备注列：
  - `remark`
- 机器备注只应更新自己的标准化片段，不应无条件覆盖人工备注。

## 浏览器状态边界

- 浏览器页面对象只存在于运行时内存，不持久化到数据库。
- 数据库存储的是业务状态：
  - 当前任务进度
  - 当前浏览位置
  - 当前项草稿
  - 已提交结果
