# Upstream Creator Collection

`creator_collector` 是工作流的上游采集阶段。

职责：

- 打开受控浏览器
- 复用由 `LinkGlancer` 管理的浏览器配置及其内部 profile
- 等待人工完成登录和筛选准备
- 捕获 creator marketplace list 的真实请求上下文
- 按分页参数持续拉取结果
- 持续保存已获取数据
- 在用户确认结束后导出标准 `xlsx`

约束：

- 只采列表数据，不采详情页
- 不引入国家任务概念，页面 URL 由配置提供
- 单次采集任务对应一次采集和一次导出
- 异常时暂停，提示“请处理后点继续”

补充说明：

- 下游任务创建后，可以在任务页基于 `creator_oecuid` 启动独立的补充采集能力。
- 补充采集属于任务内数据增强，不回写上游列表采集结果文件。
- 补充采集按 `selection_region` 分组执行，直接写回任务数据并参与正常导出。

边界：

- 不直接写审核数据库
- 不复制审核任务创建逻辑
- 通过 `LinkGlancer` 暴露的应用层接口进入下游阶段
